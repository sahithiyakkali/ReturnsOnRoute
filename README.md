# Returns on Route

A product concept case study: letting car-free renters hand returns to the Amazon driver already at their building → https://sahithiyakkali.github.io/ReturnsOnRoute/

I recently moved somewhere without a car, and the nearest Amazon return point is a 15-18 minute walk away. I noticed I had started avoiding orders I used to make without thinking, so I interviewed 32 residents of my apartment building to see if I was alone. Every car-free resident I spoke to (24 of 24) hesitated to order because of returns; none of the residents with a car did. This is the concept that came out of that: hand a return to the delivery driver who is already at the building, or use a secure campus kiosk. Includes the research, options considered, solution design, risks, a pilot plan with kill criteria, and a full PR/FAQ.

An independent concept, not affiliated with or endorsed by Amazon.
